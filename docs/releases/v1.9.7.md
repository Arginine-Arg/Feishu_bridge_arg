# arg-bridge v1.9.7

This patch keeps the v1.9.6 Broker and `/btw` runtime fixes and corrects the
cross-version CI gate.

## Fixed

- The third-party Codex wrapper regression still runs on Node 22 and Node 24,
  where `node:sqlite` is available.
- The same test is skipped on Node 20, which does not provide `node:sqlite`.
  This removes false failures from Node 20/Ubuntu and Node 20/macOS CI without
  changing production behavior.

v1.9.6 remains available. Upgrade to v1.9.7 when a fully green Node 20 through
24 CI matrix is required.

## Validation

- Typecheck, build, package installation, full local tests, real
  `hallong_ds` Broker rounds and real consecutive `/btw` turns pass.
- GitHub CI must pass on Node 20/22/24, Ubuntu, macOS, and Windows before this
  patch is published.
