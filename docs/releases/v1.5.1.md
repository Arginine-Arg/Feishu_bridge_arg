# arg-bridge v1.5.1

修复 tmux 动态发现对 Codex 命令参数的边界处理。

- `codex resume -m ...`、`codex resume --model ...` 等没有明确 session ID 的命令不再把 `-m` 或其他 CLI 选项误当作 thread ID。
- 只有明确的 `resume <id>` 才会出现在 `/tmux list` 的 structured 候选中。
- v1.5.0 的 legacy pane 自动迁移、App Server 自动启动和一对一 scope 绑定行为保持不变。

升级后重新启动对应 profile：

```bash
arg-bridge restart --profile codex
```
