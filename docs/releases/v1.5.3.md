# arg-bridge v1.5.3

修复慢速 legacy Codex pane 迁移的 RPC 超时处理。

- `thread/resume` 使用更长的迁移窗口；超时后只轮询 `thread/loaded/list` 等只读状态，不重复发送这个有副作用的请求。
- 如果原请求最终成功，Bridge 会继续创建并绑定 remote pane；如果状态始终未确认，则不创建 pane。
- 本次迁移新建的 pane 在后续校验失败时会被清理，旧用户 pane 保持不变。

升级后重新启动对应 profile：

```bash
arg-bridge restart --profile codex
```
