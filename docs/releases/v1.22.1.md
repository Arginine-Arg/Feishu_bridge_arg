# arg-bridge v1.22.1

The guided subagent settings now use one provider/model priority list for read-only `/btw` sides, workspace-write workers, model-visible Broker tools and RSI reviewers. The advanced section contains permissions, concurrency, waiting, reasoning fallback, web search and MCP controls; it no longer asks for a separate model, fixed write route or “follow /btw model” choice.

For a fixed provider, settings reads its authenticated model catalogue and saves one or two selected models in order. Reopening settings preserves those selections. “Follow current provider” reads that provider’s configured default model for each new dispatch. Priority routing also accepts a selected backup provider instead of rejecting it because it differs from the primary. A provider/model that fails is cooled for future dispatches; active workers are retained and never replayed to a fallback route.

When saving an old profile, legacy `providerOverrides.model` values are cleared and their reasoning settings remain. `writeRoute` remains readable for old manual profiles but the guided UI saves it empty. The main Codex provider is unaffected.

Upgrade:

```bash
curl -fsSL https://github.com/Arginine-Arg/Feishu_bridge_arg/releases/download/v1.22.1/install-global.sh -o /tmp/install-arg-bridge.sh
sh /tmp/install-arg-bridge.sh --version 1.22.1
hash -r
arg-bridge --version
```

Reload settings with `arg-bridge settings --profile codex`. Existing running workers keep their current route; new tasks use the saved priority list.
