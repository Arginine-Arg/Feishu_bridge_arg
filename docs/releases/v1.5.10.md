# arg-bridge v1.5.10

修复 Linux tmux pane 中 shared Codex endpoint 未被识别的问题。

- `/proc/<pid>/cmdline` 受限或 pane PID 关系不完整时，使用 `TMUX` server socket + `TMUX_PANE` 精确关联当前 Codex 进程，再以 pane cwd 作为保守回退，最后读取 `ps` 命令行。这样不同 tmux server 中重复的 `%0`/`%1` 不会互相污染。
- 支持 Node wrapper、bundled Codex、bash wrapper，重复进程身份会去重；多个 pane 共用 cwd 时优先精确 pane 标记。
- 保留 `/tmux list` 自动生成 structured resume 命令和 `/tmux release` 安全解除 managed 标记功能。
