# arg-bridge v1.5.4

修复 Codex pane 退出后无法继续迁移的问题。

- Bridge 保存最近发现的 `threadId、tmux socket、session、workspace、CODEX_HOME`，Codex pane 退出后仍在 `/tmux list` 显示为已保存候选。
- `/tmux bind` 可以从已退出的 legacy pane 候选重新创建 structured pane；如果原 tmux session 也已关闭，会按保存的 session 名称创建新 session。
- 旧 thread 会先通过 `thread/resume` 验证，只有确认成功才创建 pane；失败不会留下新 pane。
- 慢速 `thread/resume` 超时只进行只读状态确认，不会重复发送有副作用的请求。

默认 workspace 不会被修改；候选绑定仍按 Bot profile 和 Feishu scope 隔离。
