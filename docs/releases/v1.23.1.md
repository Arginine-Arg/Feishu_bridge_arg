# arg-bridge v1.23.1

This release contains the DeepSeek Harness profile and worker integration from
v1.23.0. Its release workflow now runs the official Harness regression with
the same bounded Linux process concurrency used by the passing CI gate.

Update command:

    curl -fsSL https://github.com/Arginine-Arg/Feishu_bridge_arg/releases/download/v1.23.1/install-global.sh -o /tmp/install-arg-bridge.sh
    sh /tmp/install-arg-bridge.sh --version 1.23.1
    hash -r
    arg-bridge --version
