# arg-bridge v1.23.4

Bind a shared Codex App Server session with `/tmux bind`. When a terminal turn completes, Bridge sends its answer to the bound Feishu chat or topic. Feishu input continues on that same thread and inherits its permissions. Use `/model` to select the next turn's model and `/status` to see the selection.

The Linux pilot used Magpie with Getrich, Xinlab and the official Gemini API. See the [English setup](../../README.md#switch-providers-within-a-shared-codex-session) and [中文配置](../../README.zh.md#在同一个-codex-会话里更换供应商).

```sh
curl -fsSL https://github.com/Arginine-Arg/Feishu_bridge_arg/releases/download/v1.23.4/install-global.sh -o /tmp/install-arg-bridge.sh
sh /tmp/install-arg-bridge.sh --version 1.23.4
hash -r
arg-bridge --version
```
