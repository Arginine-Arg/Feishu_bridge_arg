# arg-bridge v1.13.2

This patch fixes explicit `/steer` for active goal continuation turns.

## Fixed

- A `/goal resume` request is submitted as a structured native command run.
  That run can stay active while Codex starts and continues model turns.
  Steering now checks the active Codex session's real turn state instead of
  rejecting the entire command run.
- Other structured control paths can use steering when they have an active
  Codex turn, including ongoing goal work.
- Steering remains unavailable between goal turns and while Codex is waiting
  for an interaction or approval response. An explicit App Server rejection
  still returns unavailable without queueing or retrying the message.

## Usage

```text
/goal resume

# while the goal has an active model turn:
/steer prioritize the five benchmark tasks
```

Use `/status` to inspect the current steer availability.
