# arg-bridge v1.20.0

Fixes Bridge recovery interrupting Codex before its native reconnect attempts
could complete, and removes the long injected continuation prompt.

The 60-second watchdog polls turn state and sends at most three idempotent
`turn/steer` nudges containing `continue` to the active turn. It never
interrupts the turn. Codex keeps its native reconnect budget, including its
default five reconnect attempts. Confirmed terminal failures and
retry-associated interruptions begin another same-thread round with exactly
`continue`.

Bridge allows three continuation rounds. Real assistant text, reasoning or tool
progress resets the active-round nudge count. Exhaustion never interrupts a
live turn: the original Codex terminal error is shown. Explicit lower profile
budgets remain supported. User stops, paused goals, provider restrictions and
non-retryable errors remain respected.

Update and restart each profile. Existing bound sessions need no new native
adoption. The complete structured text delivery fixes from 1.19.0 are retained.

Validation includes virtual long-session tests, three active-turn nudges, native
reconnect preservation, three continuation rounds, terminal-state
reconciliation, stop races, unavailable status queries, original errors and
real Codex fault-injection tests. The release workflow runs the complete source
suite, type checks, build and archive install.
