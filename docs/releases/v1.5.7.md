# arg-bridge v1.5.7

修复 Linux 主机上正确的 shared Codex pane 被误判为 live fallback。

- `/proc/<pid>/cmdline` 不可读或为空时，structured discovery 回退到 `ps` 命令行。
- 支持 shell 包装命令启动的 remote Codex，并去重 Node wrapper 与 bundled Codex 子进程。
- 同一 pane 同时出现旧启动文本和当前 remote 身份时，优先唯一的 remote endpoint；不同 active endpoint 仍拒绝猜测。
- 手动建立的 external tmux pane 与 Bridge managed pane 使用相同识别路径。
- `/tmux list` 和 `/tmux bind` 对普通 `codex resume` 会显示从当前 pane 读取的 thread 以及完整 `cd /path`、`clash on`、`arg-bridge native <thread>` 命令。

YOLO 权限、Clash 代理继承、structured 优先/live 回退和原 pane shell 保持行为沿用 v1.5.6。
