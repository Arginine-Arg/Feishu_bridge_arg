# arg-bridge v1.7.0

This release makes cross-provider `/btw`, `cc-switch` routing, Project RSI and
provider switching diagnosable and reproducible without editing installed
`dist` files.

## Highlights

- Optional MixAgents Broker backend implementing the official six-tool MCP
  surface, with a visible Codex fork fallback in auto mode.
- Every `/btw` reloads profile settings, cc-switch metadata, route mapping and
  MixAgents routes. Main provider selection remains owned by cc-switch.
- `/btw` is always read-only; route and route-fingerprint changes end the old
  side agent before a new one is created.
- New `arg-bridge settings --profile codex` and
  `arg-bridge doctor --profile codex --json` panels.
- `doctor --probe-route <id>` is a separate explicit paid read-only generation
  check with no fallback or replay.
- Configured cc-switch provider ID, Codex-internal provider ID/model, running
  App Server identity and Broker route ID are shown separately.
- Idle old threads move to the current provider/model even when the historical
  provider still exists; active turns are never switched mid-request.
- Project RSI completion gates require project/thread/task-bound fresh upstream
  evidence and validator receipts.
- `arg-bridge codex [thread]` alias and `migrate-local-poc` dry-run/apply flow.

## Security

- Bridge never runs `cc-switch ... provider current`.
- Provider secrets are never printed, logged, exported, or placed in MixAgents
  argv.
- MixAgents-managed credential delegation passes only an opaque provider
  reference. Until the external helper compatibility probe exists, doctor
  reports `delegated-unverified`.
- MCP child processes inherit only the environment intentionally available to
  the bridge service and the provider reference, never a globally exported
  Bridge secret.
- App Server replacement is deferred while another client is active.

## Upgrade and rollback

Profiles remain schema version 2 and new fields are optional. Back up config
before migration:

```bash
arg-bridge migrate-local-poc --profile codex --dry-run --json
arg-bridge migrate-local-poc --profile codex --apply
arg-bridge restart --profile codex
```

Rollback uses the printed `.local-poc-*` backup paths. Existing runs, proposals,
validator receipts and the append-only Project RSI ledger must not be deleted.
Historical Task RSI directories are not renamed or treated as Project RSI.

## Known external dependency

The MixAgents Broker package available during this implementation is private
`0.1.1` and requires an explicit MCP entry point. arg-bridge therefore does not
guess a plugin-cache path or silently install a plugin. One-click reuse of a
cc-switch secret requires MixAgents or its trusted helper to implement and
version the opaque credential-provider protocol described in the docs.

Full commands, exit codes, route/provider/model/access and explicit
non-claims are recorded in [the v1.7.0 smoke report](../smoke-v1.7.0.md).
