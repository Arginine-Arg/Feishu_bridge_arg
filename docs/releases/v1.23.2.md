# arg-bridge v1.23.2

This release improves recovery for slow or unstable upstream providers.
It distinguishes provider reconnects, network waits, response-stream errors,
and silent Working turns. Bridge observes first and does not interrupt a
provider automatically.

When a user confirms that the current turn is stuck, send /recover continue.
Bridge verifies the current turn state before sending continue. It refuses to
interrupt an active approval or tool operation.

Update with:

    curl -fsSL https://github.com/Arginine-Arg/Feishu_bridge_arg/releases/download/v1.23.2/install-global.sh -o /tmp/install-arg-bridge.sh
    sh /tmp/install-arg-bridge.sh --version 1.23.2
    hash -r
    arg-bridge --version
