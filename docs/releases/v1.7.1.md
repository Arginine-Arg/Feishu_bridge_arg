# arg-bridge v1.7.1

This patch keeps the v1.7.0 MixAgents, dynamic routing, provider-resume,
settings/doctor and Project RSI feature set while fixing cross-platform CI.

## Fixes

- Canonicalize a manifest's declared Project RSI project root before comparison,
  including macOS `/var -> /private/var`.
- Use host-correct path containment for Project RSI evidence directories on
  Windows.
- Resolve App Server socket paths before validating the canonical parent chain,
  while still rejecting group/world-writable real parents.
- Detect macOS Unix-socket clients through `lsof`; Linux continues to use
  `/proc/net/unix`.
- Skip Unix-socket-only structured process tests on Windows, where this backend
  is explicitly unsupported. The assertions remain active on Linux and macOS.
- Compare relative `CODEX_HOME` expectations with the host path implementation
  in Windows tests.

## Upgrade

No profile schema migration is required from v1.7.0. Install the new tarball or:

```bash
curl -fsSL https://github.com/Arginine-Arg/Feishu_bridge_arg/releases/latest/download/install-global.sh | sh
arg-bridge --version
arg-bridge restart --profile codex
```

The v1.7.0 smoke evidence and external MixAgents/Project RSI dependency notes
remain in [smoke-v1.7.0.md](../smoke-v1.7.0.md).
