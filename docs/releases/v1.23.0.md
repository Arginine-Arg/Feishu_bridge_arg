# arg-bridge v1.23.0

- DeepSeek Harness profiles support structured Feishu replies, approval
  cards, `/model`, `/status`, `/stop`, `/new`, `/resume`, and `/btw`.
- DSH reads its provider and model from cc-switch and releases its session
  write lock after each turn. Switching providers keeps the DSH session ID.
- Automatically configured MixAgents routes for a DSH profile run workers
  in DeepSeek Harness. Workers support progress, interruption, follow-up, and
  result lookup after a Broker reconnect.

```sh
curl -fsSL https://github.com/Arginine-Arg/Feishu_bridge_arg/releases/download/v1.23.0/install-global.sh -o /tmp/install-arg-bridge.sh
sh /tmp/install-arg-bridge.sh --version 1.23.0
hash -r
arg-bridge --version
```

DSH is a separate installation. The tested build is
`@deepseek-ai/dsh@0.2.2-rc.1` and requires Node.js 24.9 or newer.
Linux DSH workers require Bubblewrap. See the profile migration, provider
configuration, and operating limits in the [DeepSeek Harness guide](https://github.com/Arginine-Arg/Feishu_bridge_arg/blob/v1.23.0/docs/deepseek-harness.md).
