# arg-bridge v1.23.3

The Feishu card now stays open when a structured Codex turn reports a stall. It continues receiving the assistant's reply and displays the final text when the turn ends.

Use `/recover continue` in a structured Codex chat to interrupt the current turn and send one `continue` after the interruption is confirmed. Bridge checks for pending approvals and active tools. If the turn finishes during the check, the existing answer is delivered.

In a DeepSeek Harness chat, send `/stop`, wait for the run to finish, and then send a follow-up in that chat.

```sh
curl -fsSL https://github.com/Arginine-Arg/Feishu_bridge_arg/releases/download/v1.23.3/install-global.sh -o /tmp/install-arg-bridge.sh
sh /tmp/install-arg-bridge.sh --version 1.23.3
hash -r
arg-bridge --version
arg-bridge restart --profile codex
```
