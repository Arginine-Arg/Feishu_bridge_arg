# arg-bridge v1.7.2

This patch completes the cross-platform validation follow-up to v1.7.0/v1.7.1.

## Fixes

- macOS App Server socket paths are canonicalized through `/private/var`.
- When `/proc/net/unix` is unavailable, macOS replacement/recovery is
  conservatively deferred instead of killing an ambiguous socket holder.
- Unix socket symlink resolution validates the canonical parent chain, including
  `/var -> /private/var`, without rejecting safe system symlinks.
- Windows tests use host-native path normalization and directory-backed
  unreadable-file fixtures.
- Project RSI status tests keep initialization, validator, and fresh-run
  assertions active on all platforms.

No configuration or state migration is required from v1.7.0/v1.7.1.
